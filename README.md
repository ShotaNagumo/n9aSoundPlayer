# n9a Music

Android 15 以上を対象にした、端末ローカルストレージの WAV／MP3 を再生する個人用音楽プレーヤーです。

## 実装済みの機能

- ローカルストレージ上の WAV／MP3 の一覧と再生
- 再生／一時停止、前後の曲、シークバー、10 秒戻る／進む
- リピートの 3 状態（オフ／全曲／1 曲）
- プレイリストの作成、名前変更、削除、曲の追加・削除、順序変更
- 再生キュー、前回の曲・再生位置・リピート設定の復元
- バックグラウンド再生と通知からの基本操作
- ダークテーマ固定
- HSVカラーピッカーによるアクセントカラー設定
- 画面遷移を戻る操作、ルート画面で5秒以内にもう一度戻ると終了
- 明示的な終了・履歴からの削除時に再生・通知・プロセスを終了
- 曲の再生時間（hh:mm:ss）、再生回数、プレイリスト合計時間

最新の追加仕様は [docs/design/update-2026-10-14.md](docs/design/update-2026-10-14.md)、アイコンのSVG／PNGは [docs/design/icons](docs/design/icons) にあります。

## 開き方

Android Studio の **Open** でこのフォルダを選択してください。初回同期時に Android 15（API 35）SDK と対応するビルド環境が必要です。

アプリの初回起動時に、端末内の音源を読む権限と通知権限を許可してください。音源本体はアプリにコピーもアップロードもされません。

設計資料は [docs/design/audio-player-spec.md](docs/design/audio-player-spec.md) にあります。

## 開発用ファイル

アイコンの再生成は Node.js 20.9 以上で `npm install` を実行した後、`npm run render:icon` を実行してください。SVG原稿と同じ見た目のPNGを出力し、画素一致を確認します。

無音テスト音源は Python 3.8 以上で `python scripts/generate-debug-audio.py` を実行すると、`debug-audio/` に生成します。生成済みの音源はGit管理対象外です。

SDKの場所を指定する `local.properties`、作業用JDKの `.tools/`、ビルド出力、端末診断データ、署名鍵、環境変数ファイルはGit管理対象外です。リポジトリにはソースコード、設定、仕様書、採用済みアイコン、ライセンスと生成スクリプトを含めます。
