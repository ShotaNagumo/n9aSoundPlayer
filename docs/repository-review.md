# Git管理前の整理・情報点検

実施日: 2026-10-18

## 整理したもの

- 旧画面イメージ `docs/design/audio-player-screen-concept.png` を削除。現在の実装と異なる初期案のため。
- ビルド出力 `build/`、`app/build/` とプロジェクト内のGradleキャッシュ `.gradle/` を削除。これらはビルド時に再生成される。
- `.tools/` に置かれていた端末UIのXML、スクリーンショット、展開済みJDKの元ZIPを削除。端末内の情報を含む診断データを残さないようにした。
- 未使用の色リソース定義を削除。

採用済みのSVG／PNG、アイコン生成スクリプト、仕様書、ライセンスは維持した。無音WAVはデバッグ用途としてローカルに維持し、生成スクリプトのみをGit管理対象とした。

## 修正したPC固有情報

`scripts/render-icon.cjs` の依存モジュール読込先にPC固有のユーザーフォルダが指定されていたため、通常の `require('sharp')` に変更した。`package.json` に使用する依存モジュールを明記し、別のPCでも導入できるようにした。

## 点検結果

- Git管理対象候補のテキストについて、PCの絶対パス、ユーザー名、端末シリアル、メールアドレス、代表的なAPIトークン・秘密鍵・パスワード代入のパターンを検索。整理後の対象に該当は検出されなかった。
- 残した2つのPNGについて、EXIF／XMP／IPTCメタデータが含まれていないことを確認。
- Git設定に、URLへ埋め込まれたユーザー名・パスワードの組合せ、認証ヘッダー設定、パスワード／トークン設定がないことを確認。
- `n9a` は指定されたアプリ名・意匠として維持。アプリIDも更新インストールとの互換性のため維持。

正規表現検索とファイル内容の確認による点検であり、すべての形式の機密情報を検出できることを保証するものではない。

## ローカルに残す管理対象外ファイル

| 対象 | 理由 |
| --- | --- |
| `local.properties` | SDKの場所を指定するPC固有設定。Git管理対象外を確認済み。 |
| `.tools/jdk-17/` | このPCで使用するビルド用JDK。Git管理対象外を確認済み。 |
| `debug-audio/` | スクリプトから再生成できる無音WAV。Git管理対象外を確認済み。 |

ビルド出力、署名鍵、環境変数ファイル、端末診断ログ、Node.jsの依存モジュールも `.gitignore` に除外設定を追加した。Git自身の `.git/` は設定・管理データとして維持した。
