# n9a Music アイコン C

波形、再生マーク、n9a のアウトライン文字を組み合わせたマテリアルデザインのアイコン。

- 原稿: n9a-music-c.svg（512 × 512 viewBox、出力サイズ 1024 × 1024）
- PNG: n9a-music-c.png（1024 × 1024、sRGB）
- アプリ用: ic_launcher.png（512 × 512、同一SVGから生成）
- 文字はすべてパス。フォント、外部画像、色のプロファイルに依存しない。
- 色は sRGB の #101317、#A78BFA、#F3F1F6 に固定。
- scripts/render-icon.cjs でSVGからPNGを生成。Android側ではこのPNGを参照する。
