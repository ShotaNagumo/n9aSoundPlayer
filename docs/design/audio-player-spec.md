# 音声プレーヤー Android アプリ — 初期設計仕様

## 1. 目的と対象

端末のローカルストレージに保存された音声ファイルを、迷わず再生するための個人用 Android アプリです。クラウドストレージ、オンライン配信、アカウント連携は使用しません。ストア公開は想定せず、広告・分析機能も持ちません。

### 対象環境

| 項目 | 仕様 |
| --- | --- |
| 対象 OS | Android 15 以上 |
| 音源の保存場所 | 端末のローカルストレージ。アプリ内に音源を複製せず、既存ファイルを参照する。 |
| 対応音源形式 | WAV（`.wav`）および MP3（`.mp3`） |

## 2. 初期版の機能範囲

### 含める機能

| 機能 | 内容 |
| --- | --- |
| ローカル音源の表示 | 端末のローカルストレージ上にある WAV／MP3 ファイルを曲一覧に表示する。 |
| 再生制御 | 再生／一時停止、前曲、次曲、シークバー操作を行う。 |
| 10 秒シーク | `戻る 10秒` と `進む 10秒` を独立ボタンで用意する。再生位置を範囲内に収める。 |
| リピート | `オフ`、`全曲リピート`、`1曲リピート` の三状態をボタンを押すたびに順番に切り替える。 |
| プレイリスト | 作成、名前変更、削除、曲の追加・削除、並び替え、プレイリスト単位の再生を行う。 |
| バックグラウンド再生 | アプリを閉じても再生を継続し、通知およびロック画面から再生／一時停止・前後の曲を操作できる。 |
| 再開 | 最後に再生していた曲・再生位置・リピート設定を次回起動時に復元する。 |

### 初期版では含めない機能

- ストリーミング、クラウドストレージ連携、オンライン検索、ダウンロード
- アカウント、広告、課金、共有
- イコライザー、再生速度、歌詞、キャスト、Android Auto
- シャッフル、スマートプレイリスト、複数キュー

## 3. 画面構成

### 3.1 ライブラリ

- 画面名: `ライブラリ`
- 曲一覧を、アルバムアート・曲名・アーティスト名で表示する。
- 上部のショートカットで `すべての曲` と `最近追加` を切り替える。
- 行をタップすると、その曲から一覧順に再生する。
- 行のメニューから `プレイリストに追加` を行う。
- 曲の選択中は、画面下部にミニプレーヤーを表示する。タップで再生画面へ遷移する。

### 3.2 再生中

- 上部: 戻る、現在の曲名、キューを開く操作。
- 中央: アルバムアート、曲名、アーティスト名、シークバー、経過時間／総時間。
- 主操作: 前曲、`戻る 10秒`、再生／一時停止、`進む 10秒`、次曲。
- 下部: リピート切替ボタンと再生キューを開くボタン。
- リピートの表示は状態と連動する。
  - オフ: 通常色のリピートアイコン
  - 全曲: 紫のリピートアイコン、ラベル `全曲リピート`
  - 1曲: 紫の `1` 付きリピートアイコン、ラベル `1曲リピート`

### 3.3 プレイリスト

- 画面名: `プレイリスト`
- 作成済みプレイリストを、名称・曲数・代表アートワークで表示する。
- 右下の追加ボタンから名前を入力して作成する。
- 詳細画面では曲の削除とドラッグによる並び替えを行う。
- 再生を開始すると、そのプレイリストの順序が再生キューになる。

## 4. 操作ルール

| 操作 | 動作 |
| --- | --- |
| `戻る 10秒` | 現在位置から 10 秒戻る。0 秒未満にはしない。 |
| `進む 10秒` | 現在位置から 10 秒進む。曲末を超えない。 |
| 前曲 | 曲の再生位置が 3 秒より後なら曲頭へ戻す。3 秒以内なら前の曲へ移動する。 |
| 次曲 | キュー内の次の曲へ移動する。末尾では、全曲リピート時のみ先頭へ戻る。 |
| 曲の終了 | オフでは停止、全曲リピートでは次曲へ、1曲リピートでは同じ曲の先頭へ戻る。 |
| 曲をプレイリストへ追加 | 複数のプレイリストへの重複登録を許可する。同一プレイリスト内の重複は許可しない。 |

## 5. UI デザイン指針

- テーマ: ダークモード固定。端末テーマの変更に追随しない。
- 背景: 黒に近いグラファイト `#101317`。カードは `#1A1F25`。
- 強調色: 紫 `#A78BFA`。再生中・選択中・有効なリピートにのみ用いる。
- 文字: 主テキストは白に近い色、補助テキストは低彩度のグレー。コントラストを優先する。
- 操作性: 最も重要な再生／一時停止を大きく中央に置き、10 秒操作を左右に独立配置する。アイコンだけに依存せず、10 秒操作にはラベルを付ける。
- アニメーション: 再生ボタンの状態変化、ミニプレーヤーから再生画面への遷移のみ。装飾的な演出は避ける。

## 6. データの扱い

- 音源本体は端末のローカルストレージ上の WAV／MP3 ファイルを参照し、アプリ内やクラウドへ複製・アップロードしない。
- アプリ内にはプレイリスト、曲 URI、並び順、最終再生状態のみを保存する。
- 音源が削除または移動され参照できなくなった場合は、一覧で再生不可として表示し、プレイリストから削除できるようにする。

## 7. 受け入れ条件

1. 任意のローカル音源を選び、再生・一時停止・前後の曲移動ができる。
2. `戻る 10秒` と `進む 10秒` が正しく再生位置を動かす。
3. オフ／全曲／1曲リピートが、画面表示と実際の終了時動作の両方で一致する。
4. プレイリストを作成し、曲の追加・削除・並び替え・再生ができる。
5. バックグラウンド再生中に通知から最低限の再生操作ができる。
6. 全画面がダークテーマと紫の強調色で統一され、本文・操作ラベルが読み取れる。
